강점 (Top 5)

  1. 검증된 레이어드 모놀리스: einterfaces/ 추상화로 테스트 가능성과 확장성을 동시에 확보. 29종 잡 시스템·WebSocket 실시간 통신이 긴밀하게 통합됨.
  2. 포괄적 CI/CD: 43개 GitHub Actions 워크플로로 단위·통합·E2E·야간 레이스 컨디션·보안 스캔·i18n·마이그레이션 자동화를 망라.
  3. 다중 배포 환경: 단일 바이너리 + Docker 4종(FIPS 포함) + Kubernetes/Helm + 주요 Linux 배포판 패키지로 규제 산업까지 커버.
  4. 오픈코어 경계 명확: enterprise/ blank import 패턴으로 MIT 코어와 상용 기능 경계가 투명하게 분리됨.
  5. 현대적 프론트엔드 모노레포: 7개 npm 워크스페이스(API 클라이언트·Redux·타입·UI·ESLint 플러그인)로 관심사 분리 우수.

위험 / 개선 필요 사항 (Top 5)

  1. PostgreSQL 단독 의존: pgvector 등 전용 기능 증가로 이식성 저하 및 운영 부담 집중 우려.
  2. CHANGELOG 외부 의존: 리포 내 릴리스 히스토리 부재로 오프라인 감사·자동화 도구 연동 어려움.
  3. 모놀리스 성장 한계: channels/app/이 16개 서브패키지로 누적되어 빌드·테스트 시간 및 팀 소유권 충돌 리스크.
  4. Dependabot/Renovate 미확인: 50+ Go 의존성과 7개 npm 워크스페이스의 자동 취약점 패치 메커니즘 불명확.
  5. E2E 이중 체계 비용: Cypress→Playwright 이행 중 두 프레임워크 병행 유지로 CI 시간 및 개발자 인지 부하 증가.
