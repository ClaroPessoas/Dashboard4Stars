9. 자주 묻는 질문 / FAQ

[한국어]

Q1. pnpm install 중 "peer dependency" 경고가 많이 나옵니다. 무시해도 되나요? 네. pnpm-workspace.yaml에 strictPeerDependencies: false가 명시되어 있습니다. 경고는 무시하고 설치를 계속 진행하세요.

Q2. docker compose up을 실행했는데 MongoDB에 연결이 안 됩니다. MongoDB는 Replica Set 초기화에 10~20초가 걸립니다. docker compose logs setup 으로 초기화 완료 여부를 확인하세요. AlreadyInitialized 메시지가 보이면 정상입니다. 그래도 연결이 안 된다면 MONGOHQ_URL에 ?directConnection=true 파라미터가 있는지 확인하세요.

Q3. Auth0 설정 없이 로컬에서 로그인 테스트를 하고 싶습니다. .env에 FCC_ENABLE_DEV_LOGIN_MODE=true를 설정하면 http://localhost:3000/signin/dev 엔드포인트가 활성화됩니다. 이를 통해 Auth0 없이 개발용 사용자로 즉시 로그인할 수 있습니다.

Q4. 클라이언트 빌드가 curriculum.json not found 에러로 실패합니다. client 빌드는 curriculum 패키지의 빌드 결과에 의존합니다. pnpm build:curriculum을 먼저 실행하거나, pnpm build (Turborepo가 순서 자동 처리)를 사용하세요.
