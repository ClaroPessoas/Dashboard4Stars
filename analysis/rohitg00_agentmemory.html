1. 프로젝트 개요 / Project Overview

1.1 목적 및 분류 / Purpose and Classification

해결하는 문제 / Problem solved: AI 코딩 에이전트(Claude Code, Cursor, Copilot CLI, Codex 등)가 세션 간 컨텍스트를 잃는 문제를 해결하는 로컬 우선(local-first) 영속 메모리 런타임. LLM 에이전트의 관측 결과(observation)를 자동으로 캡처·압축·검색 가능한 형태로 저장하여, 에이전트가 이전 세션의 맥락·결정·패턴을 회상할 수 있게 한다.

This project solves the "stateless agent" problem: AI coding agents (Claude Code, Cursor, GitHub Copilot CLI, Codex, Gemini CLI, etc.) lose all context between sessions. agentmemory provides a local-first persistent memory runtime that automatically captures, compresses, indexes, and retrieves agent observations via MCP and a REST API, enabling cross-session recall without an external database.

분류 / Classification: Platform / Tool — MCP-compatible memory server, deployable as a daemon, with a REST API (126 endpoints), a web viewer, and npm packages.

Q5: npm test 에서 일부 테스트가 타임아웃됩니다.

test/integration.test.ts 와 test/integration-plaintext-http.test.ts 는 라이브 서버를 필요로 합니다. 기본 npm test 명령은 이들을 제외하므로, 만약 통합 테스트가 실행된다면 npm run dev를 먼저 실행하세요.

Q6: Windows에서 일부 테스트가 실패합니다.

test/obsidian-export.test.ts 가 /tmp/ 경로를 하드코딩합니다. Windows에서는 WSL2 사용을 권장하며, 이 테스트는 CI에서도 Windows를 제외합니다.
