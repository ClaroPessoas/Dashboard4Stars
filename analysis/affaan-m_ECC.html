1. 프로젝트 개요 / Project Overview

1.1 목적 및 분류 / Purpose and Classification

해결하는 문제 / Problem solved: 다양한 AI 코딩 어시스턴트(Claude Code, Codex, Cursor, OpenCode, Gemini, Zed, GitHub Copilot)에서 일관된 에이전트 워크플로우를 운영할 수 없다는 문제를 해결한다. 에이전트 스킬(skill), 훅(hook), 규칙(rule), MCP 설정을 단일 소스에서 관리하고 다중 하네스(harness)에 배포하는 크로스-하네스 에이전트 운영 시스템을 제공한다.

ECC (Everything Claude Code) / ecc-universal is a harness-native agent operating system that packages production-ready skills, hooks, rules, agents, and MCP configurations as a single installable plugin across multiple AI coding environments. It eliminates the need to maintain separate workflow definitions per IDE/AI tool.

분류 / Classification: Platform / Tool (AI Agent Operations Infrastructure)

1.2 소프트웨어 스택 / Software Stack

구분 / Category 내용 / Details
언어/런타임 / Language & Runtime Node.js ≥18 (primary, CommonJS), Python ≥3.11 (LLM abstraction layer), Rust 2021 edition (ecc2 alpha TUI)
프레임워크 / Framework 없음 (No external framework); custom plugin/manifest architecture
데이터 저장소 / Data Store SQLite (via sql.js npm + rusqlite in ecc2), JSON manifest files
통신 방식 / Communication MCP (Model Context Protocol) over stdio/HTTP; REST via ureq (Rust); local IPC via named sockets
배포 환경 / Deployment npm package (ecc-universal), install scripts (Bash/PowerShell), GitHub App (ecc-tools)
패키지 관리자 / Package Manager Yarn 4.9.2 (primary); npm/pnpm/bun 호환 지원

종합 판정 / Overall Verdict: 🔵 Review (조건부 채택 / Conditional Adoption)

한국어 판정 근거: ECC(ecc-universal)는 라이선스 관점에서 상용화에 매우 적합하다. MIT 라이선스와 100% Permissive 의존성 스택은 소스 공개 의무 없이 상업적 제품에 내장하거나 SaaS로 운영할 수 있음을 의미한다. 보안 체계(공급망 IOC 스캔, SHA 고정 CI, SECURITY.md)도 AI 에이전트 플랫폼 기준으로는 평균 이상이다. 그러나 두 가지 조건이 충족되어야 프로덕션 상용화를 권고할 수 있다: (1) 버전 GA 확인 — 2.0.0-rc.1의 정식 릴리스가 필요하며, ecc2 Rust TUI 알파 컴포넌트는 프로덕션 의존성으로 사용하지 않아야 한다. (2) 법적 컴플라이언스 보완 — NOTICE, THIRD_PARTY_LICENSES, SBOM 파일을 채택 조직 내부에서 직접 생성·관리해야 하며, 라이선스 자동 스캔 게이트를 CI에 추가해야 한다.

English rationale: ECC is commercially well-positioned due to its all-permissive license stack (MIT project + zero copyleft dependencies), active release cadence (~2-week cycles), cross-harness portability, and an existing dual-open-source/commercial model (ECC Pro at $19/seat). The primary caution signal is the single-maintainer dependency risk and the absence of formal compliance artifacts (NOTICE, SBOM). Adopters should treat this as a Review case: conduct internal license verification for the 8 UNKNOWN-tagged packages (all confirmed permissive externally), generate a SBOM at adoption time, document a contingency plan for maintainer unavailability, and wait for a stable GA release before critical production dependency.
