1. 목적과 범위 (Purpose & Scope)

KR. Claude Code 위에서 동작하는 "학술 연구 부조종사(copilot)" 스킬 묶음. 연구 질문 정의 → 심층 리서치 → 논문 작성 → 무결성 점검 → 동료심사 → 개정 → 최종 포맷팅의 10단계 파이프라인을 사람-인-더-루프(human-in-the-loop)로 자동화한다. deep-research, academic-paper, academic-paper-reviewer, academic-pipeline 4개 Skill + 25개 모드(MODE_REGISTRY.md) + 32+ 에이전트로 구성. 대상 사용자는 연구자/대학원생/심사자이며 상업 SaaS 용도는 라이선스로 금지됨. v3.8 이후는 Zhao et al. (arXiv:2605.07723) 의 14만+ 환각 인용 보고에 대응하여 L3 claim-faithfulness 게이트(인용 anchor + opt-in audit pass + 5개 HIGH-WARN refuse rule)에 초점.

EN. A "research copilot" plugin suite for Claude Code that orchestrates a 10-stage human-in-the-loop pipeline (research → write → integrity gate → review → revise → final integrity → finalize). It is not a library or autonomous agent — it is a prompt + protocol artifact: ~100 lint scripts, ~100+ markdown agent specs, JSON Schemas (sprint contract, literature corpus, compliance report, claim audit), and validation tests. Aimed at academic researchers; commercial use prohibited by CC BY-NC 4.0.

4. 아키텍처 (Architecture)

  • 엔트리포인트: Claude Code가 */SKILL.md frontmatter (name, model: inherit, data_access_level, task_type)를 로드. /ars-* 슬래시 커맨드 10종은 commands/ars-*.md에 모델 라우팅 고정.
  • 모듈 경계: 4-skill 분리(Stage 책임). Skill 간 통신은 Material Passport (Schema 9, append-only reset_boundary[] ledger + literature_corpus[] + compliance_history[]) 한 가지 데이터 컨트랙트로 통일.
  • 계층: "agents = 도메인 로직 / shared = 횡단 정책 / scripts = 검증 lint / .github = 게이트". 각 Skill 내부에 agents/(역할 정의) + references/(프로토콜) + templates/ 의 일관된 4분 구조.
  • 데이터 액세스 계층화: raw(deep-research) → redacted(academic-paper) → verified_only(reviewer/pipeline). check_data_access_level.py로 lint.
  • 아키텍처 패턴: Multi-agent pipeline orchestrator + Contract-driven gating.
  • Sprint Contract (Schema 13.1) — generator(writer) / evaluator / reviewer 3-모드 사전 약속(pre-commitment) → paper-blind Phase1 → paper-visible Phase2.
  • Integrity Gates Stage 2.5 / 4.5 — 7-mode AI failure checklist (Lu 2026 Nature).
  • L3 Claim Audit (v3.7.3 + v3.8) — <!--ref:slug--><!--anchor:<kind>:<value>--> 3-layer citation + opt-in ARS_CLAIM_AUDIT=1 audit pass + 5종 HIGH-WARN annotation을 formatter terminal hard gate(REFUSE rules 6-10)가 차단.
  • Cross-index triangulation (v3.9.0) — S2 + OpenAlex + Crossref unmatched 신호 → 4-tier CONTAMINATED-* advisory suffix.
  • 통신: Skill 간은 file-passing(Material Passport), 모델 간은 옵션 ARS_CROSS_MODEL (GPT-5.4 Pro / Gemini 3.1 Pro independent DA critique).
  • 상태 관리: Passport reset_boundary[] hash chain (canonical JSON + SHA-256, pending_decision 필드) → 옵션 ARS_PASSPORT_RESET=1로 신규 Claude 세션에서 resume_from_passport=<hash> 재개 가능.
