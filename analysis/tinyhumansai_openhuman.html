4. 아키텍처 / Architecture

전체 모델: Tauri 데스크탑 셸 안에 Rust core를 in-process tokio task로 실행 (PR #1061에서 sidecar 제거). 프런트↔코어 통신은 127.0.0.1:<port>/rpc로 HTTP JSON-RPC (per-launch bearer in OPENHUMAN_CORE_TOKEN), Tauri IPC를 통해 CORS 우회 (core_rpc_relay).

  • Entry points:
  • Rust: src/main.rs → openhuman-core CLI (serve, agent, memory, completion 등). 보조 바이너리 slack-backfill, gmail-backfill-3d.
  • Frontend: app/src/main.tsx → App.tsx provider chain (Sentry → Redux/Persist → BootCheckGate → CoreStateProvider → Socket → ChatRuntime → HashRouter → AppShell).

  • Tauri host: app/src-tauri/src/main.rs + lib.rs (IPC 명령 등록, CoreProcessHandle 라이프사이클 소유).

  • Rust 도메인 (src/openhuman/): 약 80개 도메인 모듈 (agent, memory, channels, cron, integrations, learning, providers, voice, screen_intelligence, scheduler_gate, tokenjuice, webview_accounts, …). 각 도메인은 mod.rs (export-only) + ops.rs/store.rs/rpc.rs/schemas.rs 컨벤션. 컨트롤러 레지스트리 패턴으로 RPC + CLI 단일 노출, RpcOutcome<T> 계약 (AGENTS.md).

  • Transport (src/core/): dispatch, jsonrpc, cli, socketio, auth, event_bus, observability, rpc_log, shutdown. 도메인 로직 없음 — pure transport.

  • Event bus (src/core/event_bus/): 단일 글로벌 싱글톤. 두 채널:

  • Broadcast: publish_global/subscribe_global over tokio::sync::broadcast (DomainEvent non-exhaustive enum).

  • Native request/response: register_native_global/request_native_global — zero-serialization, 메서드 문자열 키 기반 일대일 dispatch. 도메인별 bus.rs 서브스크라이버 (예: cron/bus.rs, webhooks/bus.rs).

  • CEF 렌더러 격리 정책: 서드파티 origin (telegram/slack/discord 등)에 신규 JS 인젝션 금지. 모든 행위는 native CEF 핸들러 + CDP. 보안 표면을 코드 정책으로 못박음 (CLAUDE.md).

  • State management: Redux Toolkit slices (accounts, chatRuntime, channelConnections, deepLinkAuth, mascot, notification, providerSurface, socket, thread). redux-persist + PersistGate. 인증 토큰은 redux-persist에 두지 않고 in-process core가 보관.

  • Inter-component comms: HTTP JSON-RPC (frontend↔core), Socket.io (realtime), in-process event bus (Rust domains), Tauri IPC (frontend↔shell). MCP 클라이언트/서버 모두 구현 (src/openhuman/mcp_client, mcp_server).

  • 패턴 평가 (KR): 도메인 주도 + 컨트롤러 레지스트리 + 이벤트 버스. 헥사고날 성격 — src/core/가 어댑터, src/openhuman/<domain>/이 도메인. 셸이 얇고 (단지 윈도잉/IPC) Rust가 권위.

  • 포크 후 재라이선싱: 불가 — GPL-3는 라이선스 변경 시 모든 기여자 동의 필요. tinyhumansai/openhuman 단일 회사 소유라도, 외부 기여자(현재 PR #1991까지 다수)의 CLA가 있어야 함. 별도 확인 필요.

  • 시나리오 2 — 외부 고객용 변형 배포: 즉시 GPL-3 의무 발동 — 전체 소스 공개, 동일 라이선스, 특허 grant.

  • 시나리오 5 — OEM 통합: 디바이스 임베디드 → Tivoization 방지 조항(§6, Installation Information) 적용 — 디바이스 펌웨어 업데이트 키 공개 의무 가능.

[한국어] - 분류: 완성형 데스크톱 애플리케이션 + 셀프호스트 가능한 헤드리스 Rust 코어. 라이브러리가 아니고, 프레임워크에 가까운 에이전트 하네스 (agent harness) + 참조 구현. - 해결 문제: ChatGPT/Claude/Cursor 류 에이전트가 "사용자 컨텍스트 콜드 스타트" 문제로 며칠~주 단위로 학습이 필요한 것을, 20분 주기 OAuth 자동 페치 + Memory Tree 압축 (TokenJuice) + Obsidian-호환 로컬 vault 로 즉시 채워주는 것. 동시에 벤더 락인 최소화 (118+ 통합을 한 구독으로) 및 모든 워크플로 데이터를 디바이스 내 유지 (E2E 암호화). - 실전 적용 영역: ① 개인 super-agent 데스크톱 앱, ② Docker 로 셀프호스트하여 별도 코딩 에이전트 (Claude Code, Cursor, OpenCode) 의 메모리 백엔드로 활용 (memory.backend = "agentmemory"), ③ Tauri + CEF + Rust core 아키텍처 학습용 레퍼런스.

[English] - Classification: a finished desktop application plus a self-hostable headless Rust core. Not a library; it's closer to a framework / reference agent harness. - Problem solved: agent harnesses (ChatGPT, Claude Code, Cursor, etc.) start cold and need days–weeks to learn a user. OpenHuman closes that gap with a 20-minute OAuth auto-fetch loop + Memory Tree compression (TokenJuice) + Obsidian-compatible local vault while minimizing vendor sprawl (118+ integrations under one subscription) and keeping workflow data on-device (E2E encrypted). - Real-world uses: ① personal super-agent desktop app, ② self-host the core as a Docker service and point other agents (Claude Code, Cursor, OpenCode) at it via memory.backend = "agentmemory", ③ reference implementation for Tauri + CEF + Rust-core architectures.

2. 아키텍처 이해 / Architecture Overview

[한국어] - 핵심 컴포넌트: - React 앱 (app/src): UI 만 담당. CoreStateProvider 가 인증/스냅샷 보유, SocketProvider 가 실시간, coreRpcClient 가 RPC 게이트웨이. - Tauri 셸 (app/src-tauri): 데스크톱 호스트 + CEF 런타임. core_process::CoreProcessHandle 가 in-process tokio task 로 코어 기동. IPC: invoke('core_rpc_relay', …). - Rust core (src/): Axum/JSON-RPC 서버 (port 7788, bearer auth), src/core/ 는 트랜스포트 전용, src/openhuman/<domain>/ 가 도메인 로직 (agent, memory, cron, channels, providers, voice, tokenjuice…). - Event Bus (src/core/event_bus): broadcast + native typed request/response, 직렬화 없이 trait object 전달. - External: Backend API (api.tinyhumans.ai / staging), 118+ 3rd-party 통합 (OAuth + CEF child webview scanners), Socket.io. - 데이터 흐름: 사용자 액션 → React → core_rpc_relay → in-process Axum → 도메인 dispatch → SQLite + 외부 API → DomainEvent publish → subscribers (cron, webhooks, channels) → Socket.io 또는 RPC response → UI 업데이트.

3. 실전 프로젝트 적용 시나리오 / Real-World Scenarios

[한국어] - 시나리오 1 — 신규 통합 추가 (예: Linear): 1. src/openhuman/integrations/ 또는 src/openhuman/providers/ 하위에 새 도메인 폴더 생성 (mod.rs, ops.rs, schemas.rs, store.rs, bus.rs). 2. schemas.rs 에 ControllerSchema, handle_* 핸들러 정의 → src/core/all.rs 에 export. 3. OAuth 흐름은 백엔드 프록시 사용; CEF webview 가 필요하면 app/src-tauri/src/<provider>_scanner/ 추가 (init JS 주입 금지 — CDP 만 사용). 4. tests/json_rpc_e2e.rs 에 RPC 회귀 추가, pnpm test:rust. 5. React 측에서 coreRpcClient.call('openhuman.linear_…') 호출 화면 + Redux slice 추가. 6. Vitest 단위 + WDIO E2E spec (app/test/e2e/specs/linear-flow.spec.ts). - 시나리오 2 — 셀프호스트 백엔드로 활용: git clone → cp .env.example .env → OPENHUMAN_CORE_TOKEN=$(openssl rand -hex 32) 설정 → docker compose up -d → 클라이언트 (Claude Code, Cursor) 가 http://<host>:7788/rpc 에 bearer 로 접근. memory.backend = "agentmemory" (config.toml) 로 메모리만 위임. - 시나리오 3 — 새로운 Agent Tool 추가: src/openhuman/tools/ 에 tool 정의 → agentToolRegistry.ts 에 메타 등록 → OPENHUMAN_TOOL_TIMEOUT_SECS 안에 동작하도록 작성 → DomainEvent 로 진행 상태 publish (UI 가 실시간 반영). - 시나리오 4 — Memory Tree 사용: src/openhuman/memory/ API 호출로 외부 데이터 수집 → ≤3k 토큰 Markdown 청크 생성 → SQLite memory_docs (namespace column 보유) 저장 + Obsidian vault 에 .md 미러링.

[English] - Scenario 1 — Add a new integration (e.g., Linear): 1. Create a new domain folder under src/openhuman/integrations/ or src/openhuman/providers/ (mod.rs, ops.rs, schemas.rs, store.rs, bus.rs). 2. Define ControllerSchema + handle_* in schemas.rs, export via src/core/all.rs. 3. OAuth runs through the backend proxy. If a CEF webview is required, add app/src-tauri/src/<provider>_scanner/ — no new JS injection allowed; drive everything via CDP. 4. Add an RPC regression in tests/json_rpc_e2e.rs; run pnpm test:rust. 5. Wire React UI: call coreRpcClient.call('openhuman.linear_…'), add Redux slice. 6. Vitest unit + WDIO E2E spec (app/test/e2e/specs/linear-flow.spec.ts). - Scenario 2 — Self-host as a backend: git clone → cp .env.example .env → set OPENHUMAN_CORE_TOKEN=$(openssl rand -hex 32) → docker compose up -d. External clients (Claude Code, Cursor) point at http://<host>:7788/rpc with the bearer. Set memory.backend = "agentmemory" in config.toml to expose only the memory surface. - Scenario 3 — Add a new agent tool: define under src/openhuman/tools/; register metadata in agentToolRegistry.ts; respect OPENHUMAN_TOOL_TIMEOUT_SECS; publish DomainEvent progress so UI streams live updates. - Scenario 4 — Use the Memory Tree: call src/openhuman/memory/ to ingest external data → chunked into ≤3k-token Markdown → persisted to SQLite memory_docs (which already carries a namespace column) + mirrored as .md in the Obsidian vault.

6. 성능 및 확장성 고려사항 / Performance & Scalability

[한국어] - 알려진 병목: - 과거 html2md Gmail 파싱이 10KB 입력에 894MB heap 폭주 → 자체 fast_html_to_text (linear) 와 text/plain 우선화로 해결 (Cargo.toml 주석 참고). - whisper-rs / llama.cpp 빌드: macOS Tahoe / Apple Silicon -mcpu=native 문제 → GGML_NATIVE=OFF. Windows MSVC LNK2038 → 자체 fork patch (whisper-rs-sys). - CEF child webview 다수 띄우면 메모리 사용량 큼 — provider scanner 는 CDP 이벤트 기반으로 idle 시 paused 유지. - 확장 전략: - 수직: core 는 tokio multi-thread, SQLite WAL, reqwest connection pool. Apple Silicon 에서 metal feature 자동 활성화 (whisper-rs). - 수평: 데스크톱 앱은 단일 사용자/단일 디바이스 모델. 셀프호스트 core 는 stateless 가 아님 (SQLite-backed) → 단일 인스턴스 + 백업/스냅샷 권장. 분산이 필요하면 backend API (api.tinyhumans.ai) 가 담당. - 캐싱: - TokenJuice: HTML→Markdown, URL 단축, non-ASCII 제거로 LLM 입력 비용/지연 최대 80% 감소. - Memory Tree: ≤3k 토큰 청크 + 계층 요약을 SQLite 에 영구 저장하여 매 호출 재요약 회피. - skills registry: 로컬 경로 (SKILLS_LOCAL_DIR, SKILLS_REGISTRY_URL) 사용 시 변경 즉시 반영 (no cache). - 모니터링/로깅: - Rust: tracing + tracing-appender + OpenTelemetry OTLP (opentelemetry-otlp) → Honeycomb/Tempo 등에 export 가능. RUST_LOG=info 기본, debug 시 debug,openhuman::agent=trace. - Sentry 3 프로젝트: OPENHUMAN_CORE_SENTRY_DSN (core), OPENHUMAN_TAURI_SENTRY_DSN (shell), VITE_SENTRY_DSN (React). - Prometheus metrics (prometheus crate) — 메트릭 endpoint 노출. - 로컬 디버그 로그: target/debug-logs/ (bounded by scripts/debug/cli.sh).

[English] - Known bottlenecks: - Historical html2md Gmail parsing blew up to 894 MB heap on 10 KB inputs → replaced by a linear fast_html_to_text with text/plain preference (see Cargo.toml comment). - whisper-rs / llama.cpp builds: -mcpu=native fails on macOS Tahoe / Apple Silicon → GGML_NATIVE=OFF. Windows MSVC LNK2038 fixed via a forked whisper-rs-sys. - Running many CEF child webviews is memory-heavy — scanners idle on CDP events to stay parked when idle. - Scaling: - Vertical: multi-thread tokio, SQLite WAL, reqwest connection pool. Apple Silicon enables whisper-rs metal feature automatically. - Horizontal: the desktop app is single-user/single-device. The self-hosted core is not stateless (SQLite-backed) — run one instance with backups/snapshots. Distribute via the backend API (api.tinyhumans.ai). - Caching: - TokenJuice cuts LLM input cost/latency up to 80% (HTML→Markdown, URL shortening, non-ASCII stripping). - Memory Tree stores ≤3k-token chunks + hierarchical summaries in SQLite, avoiding re-summarization per call. - Skills registry: SKILLS_LOCAL_DIR / SKILLS_REGISTRY_URL reads disk every call with no cache for instant dev feedback. - Monitoring / logging: - Rust: tracing + tracing-appender + OpenTelemetry OTLP (opentelemetry-otlp) — exportable to Honeycomb/Tempo. Default RUST_LOG=info; debug e.g. debug,openhuman::agent=trace. - Three Sentry projects: OPENHUMAN_CORE_SENTRY_DSN (core), OPENHUMAN_TAURI_SENTRY_DSN (shell), VITE_SENTRY_DSN (React). - Prometheus metrics via the prometheus crate. - Local debug logs in target/debug-logs/ (bounded by scripts/debug/cli.sh).

7. 보안 체크리스트 / Security Checklist

[한국어] - 시크릿 관리: - .env, app/.env.local, **/core.token 절대 커밋 금지. - OPENHUMAN_CORE_TOKEN: 데스크톱은 셸이 메모리에 보관, 셀프호스트는 openssl rand -hex 32 후 .env 또는 secret manager. - 코어는 로컬 데이터 (자격증명, 토큰) 를 AES-GCM / ChaCha20Poly1305 + Argon2 (Cargo deps) 로 암호화. - 인증/인가: - 모든 /rpc 호출은 Bearer 토큰 필요 (public: /health, /schema, /events 만 예외). - core_rpc_relay Tauri command 만이 토큰을 알고 있음 — 프런트에 노출되지 않도록 invoke('core_rpc_relay', …) 만 사용 (raw fetch 금지). - 업데이트 RPC 는 OPENHUMAN_AUTO_UPDATE_RPC_MUTATIONS_ENABLED 로 게이트. - E2E 전용 destructive RPC openhuman.test_reset 은 e2e-test-support cargo feature 로만 노출 (배포 빌드엔 미포함). - 의존성 취약점: - Rust: cargo audit (CI 추가 권장), [patch.crates-io] 로 whisper-rs-sys fork 사용 — 정기적 upstream 동기화. - Node: pnpm audit, Renovate/Dependabot. - 알려진 고려사항: - CEF child webview 에 새 JS injection 금지 (스크래핑/공격면 확대). 모든 신규 동작은 CDP + Rust 핸들러. - tauri-plugin-opener 의 default init-iife.js 비활성화 (.open_js_links_on_click(false)). - 로그 시크릿/PII 금지, grep-friendly prefix 만 사용. Sentry before_send 필터로 PII 차단. - 코드 사이닝: macOS dev 는 self-signed (scripts/setup-dev-codesign.sh), 배포는 Apple Developer ID 필요. Windows 는 Authenticode. - SECURITY.md 의 책임공시 절차 준수 — public issue 금지.

[English] - Secret management: - Never commit .env, app/.env.local, or any core.token. - OPENHUMAN_CORE_TOKEN: desktop keeps it in shell memory; self-host generates openssl rand -hex 32 and stores in .env or a secret manager. - Local creds/tokens are encrypted with AES-GCM / ChaCha20Poly1305 + Argon2 (Cargo deps). - AuthN/AuthZ: - All /rpc calls require a Bearer token (/health, /schema, /events are public). - Only the core_rpc_relay Tauri command holds the token — the renderer must use invoke('core_rpc_relay', …) and never raw fetch. - Update RPCs are gated by OPENHUMAN_AUTO_UPDATE_RPC_MUTATIONS_ENABLED. - The destructive openhuman.test_reset RPC is exposed only under the e2e-test-support cargo feature; shipped binaries omit it. - Dependency scanning: - Rust: cargo audit (recommend wiring into CI). [patch.crates-io] pins a whisper-rs-sys fork — sync with upstream periodically. - Node: pnpm audit, Renovate/Dependabot. - Known considerations: - No new JS injection in CEF child webviews. New behavior goes through CDP + Rust handlers. - Disable tauri-plugin-opener's default init-iife.js via .open_js_links_on_click(false). - Never log secrets or full PII; keep grep-friendly prefixes. Sentry uses a before_send filter to scrub PII. - Code signing: macOS dev self-signed (scripts/setup-dev-codesign.sh); release needs Apple Developer ID.
