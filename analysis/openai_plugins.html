1. 프로젝트 개요 / Project Overview

1.1 목적 및 분류 / Purpose and Classification

해결하는 문제 / Problem solved

OpenAI Codex 플랫폼에서 동작하는 플러그인(Plugin)의 공개 예제 및 마켓플레이스 목록을 관리하는 레포지토리입니다. 플러그인은 외부 서비스(GitHub, Figma, Slack, Notion 등)와 Codex 에이전트를 연결하는 선언적 매니페스트 + 스킬(Skill) 콘텐츠 조합으로 구성됩니다. 소스 코드를 실행하는 일반 애플리케이션이 아니라 콘텐츠·구성(Content & Configuration) 레포지토리입니다.

This repository manages a curated collection of plugin examples and a marketplace registry for the OpenAI Codex platform. Plugins are declarative manifest + skill-content bundles that connect external services to Codex agents. It is a content and configuration repository, not a runnable application.

분류 / Classification: Platform Plugin Registry / Content Repository

구분 / Category 내용 / Details

프레임워크 / Framework OpenAI Codex Plugin SDK (독자 플랫폼 규격)

1.3 아키텍처 구조 / Architecture

openai_plugins/
│
├── .agents/                    ← 레포지토리 수준 에이전트 설정
│   └── plugins/marketplace.json ← 공식 마켓플레이스 목록 (172개 플러그인)
│   └── skills/plugin-creator/  ← 플러그인 생성 스캐폴딩 스킬
│
└── plugins/<name>/             ← 개별 플러그인 루트 (172개)
    ├── .codex-plugin/
    │   └── plugin.json         ← 필수 매니페스트 (이름, 버전, 라이선스, 인터페이스 등)
    ├── .app.json               ← ChatGPT App SDK 연결 ID (선택)
    ├── .mcp.json               ← MCP 서버 설정 (선택)
    ├── skills/<skill-name>/
    │   └── SKILL.md            ← 에이전트가 로드하는 Markdown 프롬프트 지식
    ├── agents/
    │   └── openai.yaml         ← 에이전트 정의 (선택)
    ├── hooks.json              ← PostToolUse 등 훅 설정 (선택)
    ├── plugin.lock.json        ← 외부 소스 스킬의 무결성 해시 잠금 (선택)
    └── assets/                 ← 아이콘, 스크린샷 (선택)

핵심 설계 패턴 / Core design pattern: 각 플러그인은 독립적인 패키지로, Codex 런타임이 매니페스트를 파싱하여 스킬과 에이전트를 동적으로 로드합니다. 런타임 자체는 이 레포지토리에 포함되지 않습니다.

Each plugin is an independent package; the Codex runtime parses the manifest to dynamically load skills and agents. The runtime itself is not part of this repository.

2.4 라이선스 호환성 분석 / License Compatibility Analysis

  • GPL 전파 위험 없음 / No GPL propagation risk: 레포지토리 내 GPL·AGPL·LGPL 라이선스 플러그인 없음
  • Apache 2.0 + MIT 혼용 호환: Apache-2.0은 MIT와 호환됨 (단방향; MIT 라이선스 소프트웨어에 Apache 2.0 플러그인을 통합 시 Apache 2.0 고지 의무 적용)
  • CC-BY-4.0 (NVIDIA): Creative Commons는 소프트웨어 코드에 적합하지 않으나, NVIDIA 플러그인의 경우 문서·스킬 콘텐츠(Markdown)에 적용된 것으로 해석됩니다. 상업적 이용 허용(Attribution 조건), 별도 저작자 표시 의무 발생
  • UNLICENSED (convex, magicpath): npm 생태계에서 "UNLICENSED"는 저작권자가 사용 권한을 부여하지 않았음을 의미합니다. 이 두 플러그인을 상업 제품에 포함하면 저작권 침해 위험이 있습니다.
  • LicenseRef-Figma-Developer-Terms: Figma Developer Terms는 Figma 서비스와의 통합에만 사용을 허용하며, 독립적 재배포나 경쟁 서비스에 사용은 금지될 수 있습니다. Figma의 Beta 조항 명시(언제든 수정·중단 가능).

English summary: No copyleft licenses present. Main risks are 2 UNLICENSED plugins (redistribution prohibited by default) and Figma's custom developer terms restricting non-Figma-integration use.

3.2 알려진 위험 요소 / Known Risk Factors

위험 / Risk 상세 / Detail

Important: The npx -y <package>@latest pattern in .mcp.json files is a supply chain risk. Commercial deployments should pin explicit versions or vendor the package.

3.3 보안 아키텍처 평가 / Security Architecture Assessment

  • 인증 방식 / Auth approach: 마켓플레이스 JSON의 policy.authentication: "ON_INSTALL" / "ON_USE" 설정으로 Codex 런타임이 인증을 위임 처리. 플러그인 레포자체에는 인증 코드 없음.
  • 시크릿 관리 / Secret management: 플러그인 레포에 시크릿 없음. 런타임 플랫폼(OpenAI Codex)에 위임됨.
  • SBOM 부재: 공급망 투명성 도구 미구축. 대규모 마켓플레이스 운영 시 권고 수준이나 현재 미적용.
  • plugin.lock.json: Figma, Notion 등 일부 플러그인에 SHA256 무결성 해시가 포함된 잠금 파일 존재. 외부 소스에서 벤더링된 스킬의 변조 탐지에 유용. 긍정적 보안 조치 / Positive security measure.
