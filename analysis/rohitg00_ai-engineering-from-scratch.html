프로젝트 개요 (Project Overview)

rohitg00/ai-engineering-from-scratch는 선형대수부터 자율 멀티에이전트 시스템까지, AI 엔지니어링 전 영역을 다루는 오픈소스 커리큘럼이다. 20개 Phase, 503개 Lesson, 약 320시간 분량의 학습 자료로 구성되어 있으며, 매 Lesson마다 재사용 가능한 아티팩트(프롬프트, 스킬, 에이전트, MCP 서버)를 산출한다. Python, TypeScript, Rust, Julia 4개 언어를 사용하고, MIT 라이선스 하에 무료로 배포된다.

강점 (Strengths)

  1. 교육 설계의 일관성: 503개 레슨 전체가 동일한 6-beat 구조(MOTTO → PROBLEM → CONCEPT → BUILD IT → USE IT → SHIP IT)를 따른다. audit_lessons.py가 CI에서 이 불변성을 자동 검증한다.

  2. 에이전트 네이티브 설계: .claude/skills/ 아래 find-your-level, check-understanding 스킬이 Claude, Cursor, Codex 등 MCP 호환 에이전트에서 바로 동작한다. 각 레슨이 재사용 가능한 프롬프트/스킬/에이전트/MCP 서버를 산출하는 "학습이 곧 도구 포트폴리오" 모델이 독창적이다.

  3. 공급망 보안 우수: GitHub Actions 워크플로우 전체가 커밋 SHA로 핀되어 있어(예: actions/checkout@34e114...) 의존성 하이재킹 위험이 낮다. 최소 권한(permissions: contents: read) 원칙도 명확히 적용된다.

  4. 자동화 파이프라인 완결성: 푸시 시 README 레슨 카운트 자동 동기화 → site/data.js 재빌드 → Vercel 배포까지 완전 자동화. 기여자가 콘텐츠만 작성하면 웹사이트가 자동 갱신된다. 루프 방지(봇 커밋 감지 + 5회 리트라이) 로직도 견고하다.

  5. 폴리글랏 + 의존성 최소화: Python, TypeScript, Rust, Julia를 다루면서도 각 언어별 의존성 허용 목록(allowlist)을 AGENTS.md에 명시해 교육 목적의 순수성을 유지한다. Rust는 stdlib만, Julia는 표준 라이브러리만 허용한다.

위험/개선 필요 사항 (Risks & Areas for Improvement)

  1. 코드 실행 CI 테스트 없음: audit_lessons.py는 파일 구조와 스키마를 검증하지만 실제 코드를 실행하지 않는다. AGENTS.md는 "Code must run" 규칙을 명시하지만, CI에서 python3 main.py 자동 실행이 없어 실행 불가 코드가 합쳐질 수 있다. 503개 레슨 중 코드 파일 수는 Python 595개, TypeScript 129개, Rust 10개, Julia 20개인 반면, 실제 테스트 파일은 Python 63개, TS 27개로 커버리지가 낮다.

  2. SECURITY.md 및 의존성 취약점 스캔 부재: 전용 보안 정책 파일이 없으며, Dependabot나 Renovate 같은 자동 취약점 스캔 도구가 설정되어 있지 않다. requirements.txt의 패키지들(torch, transformers, anthropic 등)은 취약점이 발견될 경우 수동 업데이트에만 의존한다.

  3. 사이트 통계 수동 갱신: site/stats.json은 Vercel 대시보드에서 수동으로 복사해 갱신해야 한다. 파일 자체에 "Vercel has no public analytics API"라고 명시. 자동화할 수 없는 구조적 한계가 문서화되어 있으나, 수치가 오래된 상태로 방치될 위험이 있다.

  4. 단일 기여자 의존도: git 히스토리가 얕게 클론되어 있고 (git log --all이 커밋 1개만 반환), SPONSORS.md와 AGENTS.md 모두 주요 관리자가 단일 인물(rohitg00)임을 시사한다. 커뮤니티 기여가 증가하고 있으나 핵심 설계 결정의 단일 실패 지점(SPOF)이 될 수 있다.

  5. outputs/index.json 빈 상태: 루트 outputs/index.json이 빈 배열({"prompts":[], "skills":[], "agents":[], "mcp_servers":[]})인 반면, 각 레슨의 outputs/ 폴더에는 493개의 아티팩트 마크다운이 존재한다. install_skills.py는 각 레슨을 직접 순회하므로 인덱스 파일이 사실상 dead code 상태다. 의도적 설계인지, 자동화 미완성인지 불명확하다.

도입 권고 (Adoption Recommendation)

교육 기관·팀 내 AI 온보딩·개인 심층 학습 모두에 강력 권고.

  • 기술 도입 벤치마킹: 에이전트 스킬 설계 패턴, "Build-It-First" 교육 방법론, Vercel 기반 무서버 정적 사이트 + GitHub Actions 자동화 파이프라인 조합은 유사 교육 플랫폼 구축 시 참조 아키텍처로 활용 가능하다.
  • 기여 준비도: AGENTS.md에 기여 절차가 매우 상세하며, PR 체크리스트·이슈 템플릿·CodeRabbit AI 리뷰가 갖춰져 있다. 첫 기여 진입 장벽이 낮다.
  • 운영 성숙도: 150K+ 월간 방문자, 7500+ GitHub Stars, 활발한 콘텐츠 업데이트(2026-04 Phase 4 완성, 2026-06 현재 진행 중)는 사장될 프로젝트가 아님을 시사한다.
  • 주의 사항: 코드 실행 자동 테스트가 없으므로, 팀 환경에서 포크 후 활용 시 Phase별 smoke test CI를 추가하는 것을 권장한다. 또한 Python 의존성의 버전 고정(requirements.txt에 >= 범위 지정)이 재현성 문제를 유발할 수 있으므로 pip freeze 기반 락 파일 추가를 검토해야 한다.
