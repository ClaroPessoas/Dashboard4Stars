2.4 라이선스 호환성 분석 / License Compatibility Analysis

GPL-3.0 전파 위험 (edge-tts)

edge-tts는 Python 라이브러리로서 import edge_tts 방식으로 프로세스 내부에서 동적 링크(import)된다. GPL-3.0의 "전파(propagation)" 조항에 따르면:

  • 소프트웨어를 배포(distribute)할 경우, GPL 라이브러리와 결합된 전체 작업물은 GPL-3.0 조건을 따라야 한다.
  • 배포 시나리오: Docker 이미지 배포, 패키지 인스톨러, PyPI 배포 — 모두 GPL-3.0 의무 발생
  • SaaS(서비스만 제공) 시나리오: 사용자에게 소프트웨어를 배포하지 않고 내부에서만 실행할 경우, GPL-3.0은 소스 공개를 강제하지 않는다 (AGPL-3.0과의 차이점).

결론: - 자사 서버에서만 운영하는 순수 SaaS 모델 → GPL 소스 공개 의무 없음 (단, 내부 배포·고객 배포 시 발생) - Docker 이미지 또는 설치 패키지를 외부 고객에게 배포하는 경우 → 전체 소스(GPLv3 조건 적용)를 함께 제공해야 함 - MIT와 GPL-3.0 혼재: 프로젝트 자체 MIT 라이선스와 edge-tts GPL-3.0은 배포 결합 시 비호환. 배포 형태라면 사실상 전체가 GPL-3.0으로 재라이선스되어야 한다.

Microsoft Azure TTS SDK (Proprietary)

azure-cognitiveservices-speech는 Microsoft 상용 SDK. 사용을 위해 별도의 Azure 서비스 이용 계약 및 사용료가 필요하다. 재배포에 관한 Microsoft 라이선스 조건 별도 검토 필수.

3.2 알려진 위험 요소 / Known Risk Factors

1. CORS 와일드카드 기본 설정 (app/asgi.py 57행)

origins = cors_allowed_origins_str.split(",") if cors_allowed_origins_str else ["*"]

CORS_ALLOWED_ORIGINS 환경 변수를 지정하지 않으면 모든 출처에서 API 접근 허용. allow_credentials=True와 결합되어 CSRF/CORS 오용 위험 존재.

2. API 인증 없음

FastAPI 엔드포인트에 인증 미들웨어가 없다. API 서버(:8080)가 인터넷에 노출될 경우 누구나 영상 생성 태스크를 무제한 투입 가능. 기본 listen_host = "0.0.0.0" 설정(config.py 175행)은 모든 네트워크 인터페이스를 수신.

3. Dockerfile: ImageMagick 보안 정책 비활성화 (Dockerfile 48행)

RUN sed -i '/<policy domain="path" rights="none" pattern="@\*"/d' /etc/ImageMagick-6/policy.xml

경로 접근 보안 정책을 제거. MoviePy 연동을 위한 불가피한 조치이나, 컨테이너 내부에서 ImageMagick을 통한 파일 읽기/쓰기 제한이 완화됨.

4. Dockerfile: 777 권한 설정 (Dockerfile 8행)

RUN chmod 777 /MoneyPrinterTurbo

작업 디렉토리에 전 사용자 쓰기 권한 부여. 컨테이너 탈출 취약점과 결합 시 위험.

5. 하드코딩 비밀 없음 (양호)

config.example.toml에 API 키가 빈 문자열로만 존재. config.toml은 .gitignore에 포함되어 있다고 추정 (직접 확인).

6. g4f 옵션 의존성 위험

g4f는 제3자 서비스를 역공학(reverse-engineer)하여 API를 무단 호출하는 라이브러리. 법적 위험 + GPL-3.0 라이선스. 기본적으로 비활성화되어 있으나, 설명서에 명시적으로 위험을 경고하고 있음.

3.3 보안 아키텍처 평가 / Security Architecture Assessment

시나리오 C: OEM/화이트라벨 배포 - 고객사 환경에 설치해 주는 온프레미스 납품 모델 - 시나리오 B와 동일한 배포 위험 발생 - 위험 수준: 🔴 즉각적 법적 위험

시나리오 D: g4f 옵션 의존성 활성화 - uv sync --extra g4f 실행 시 GPL-3.0 + Microsoft 서비스 ToS 위반 위험 - 프로덕션 사용 불가. 현재 README에서 명시적 경고 중 - 위험 수준: 🔴 운영 및 법적 위험
