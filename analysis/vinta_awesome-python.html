3.2 알려진 위험 요소 / Known Risk Factors

  1. 자동화 취약점 스캐닝 부재: Dependabot, Renovate, Snyk 중 어느 것도 설정되어 있지 않다. 의존성 취약점 발견은 수동에 의존한다.
  2. 의존성 EOL 위험: Python 3.13 필수 요건은 최신 버전이다. 현재 의존성은 2026년 기준 최신 버전이며 EOL 우려가 없다.
  3. 하드코딩된 시크릿: 발견되지 않음. .gitignore에 .env* 명시적 제외.
  4. exclude-newer = "3 days" (uv.toml): 최근 3일 이내 릴리스된 패키지를 자동 제외하는 공급망 공격 방어 설정이 적용되어 있다. 이는 보안 모범 사례다.
  5. actions/checkout@v6 (CI 워크플로우): 존재하지 않는 버전 태그 사용 가능성. 실제 최신 안정 버전은 v4다. @v6 태그가 유효한지 확인 필요 — 만약 미존재 시 CI 실패 또는 잘못된 버전이 실행될 수 있다.
  6. SECURITY.md 부재: 취약점 보고 경로가 공개적으로 문서화되어 있지 않다.
