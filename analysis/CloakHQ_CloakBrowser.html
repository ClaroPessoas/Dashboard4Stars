1. 프로젝트 개요 / Project Overview

1.1 목적 및 분류 / Purpose and Classification

  • 해결하는 문제 / Problem solved: 봇 탐지 시스템(Cloudflare Turnstile, reCAPTCHA v3, FingerprintJS 등)을 통과하는 스텔스 Chromium 브라우저 자동화 라이브러리. 일반 Playwright/Puppeteer가 탐지되는 문제를 C++ 소스 레벨 패치를 통해 해결함.
  • 분류 / Classification: Library + Tool (Python & JavaScript 래퍼 라이브러리 + 독점 컴파일 바이너리)

⚠️ 이중 구성 요소 경고: 이 프로젝트는 두 가지 별도 구성 요소로 구성됨. 1. 소스 코드 래퍼 (MIT 라이선스) — Python/JavaScript 래퍼 2. 컴파일 Chromium 바이너리 (CloakBrowser Binary License — 독점 상용 라이선스)

상용화 시 두 라이선스 모두 별도로 검토해야 함.

3.2 알려진 위험 요소 / Known Risk Factors

1. 하드코딩된 시크릿: 소스 코드에서 발견되지 않음. .env 파일은 .gitignore에 포함.

2. --no-sandbox 플래그: config.py에서 기본 stealth 인수에 포함됨. Chrome 샌드박스 비활성화는 Docker/컨테이너 환경에서 일반적이나, 신뢰할 수 없는 콘텐츠를 렌더링하는 환경에서는 위험.

3. SSRF 리스크 (GeoIP): geoip.py에서 프록시를 통해 외부 IP 조회 서비스(ipify.org, checkip.amazonaws.com)에 연결. 공격자가 프록시 URL을 제어할 수 있는 경우 SSRF 가능성 있음.

4. 바이너리 다운로드 소스: cloakbrowser.dev 미러 사이트 및 GitHub Releases에서 다운로드. 공식 미러 사이트의 장기 운영 보장 없음 (독립 서버).

5. P3TERX 비공식 GeoLite2 미러: GeoIP DB를 MaxMind 공식 URL이 아닌 GitHub 비공식 미러에서 다운로드. 공급망 위험 존재.

# geoip.py
GEOIP_DB_URL = (
    "https://github.com/P3TERX/GeoLite.mmdb/raw/download/GeoLite2-City.mmdb"
)

6. SECURITY.md 부재: 공식 취약점 신고 채널 없음. 현재 이메일(cloakhq@pm.me)로만 연락 가능.

7.2 강점 / Strengths

  1. 기술적 차별성: JavaScript 인젝션이 아닌 C++ 소스 레벨 58개 패치 — 탐지 우회 능력이 동급 도구 중 최상위 수준. reCAPTCHA v3 0.9점, Cloudflare Turnstile 통과 검증됨.

  2. 우수한 공급망 보안: GitHub Actions 핀 SHA, OIDC 신뢰 발행(PyPI/npm), Cosign 키리스 서명, Docker SBOM 자동 생성 — 패키지 생태계에서 보기 드문 수준의 공급망 보안.

  3. 풍부한 테스트 커버리지: 14,676줄의 테스트 코드, 보안 전용 테스트(test_lambda_security.py) 포함. SSRF, 스킴 검증, 셸 인젝션 등 보안 회귀 테스트 자동화.

  4. Playwright API 완벽 호환: 기존 Playwright 코드베이스 3줄 변경만으로 마이그레이션 가능. 동기/비동기 모두 지원, Python + JS 이중 SDK.

  5. 운영 성숙도: Docker 멀티아치 이미지, Xvfb headed 모드, AWS Lambda 통합 예제, GeoIP 자동 감지, Widevine 지원 — 프로덕션 배포를 위한 실용적 기능 완비.

7.3 위험·개선 필요 사항 / Risks and Improvement Areas

  1. 바이너리 OEM 라이선스 (치명적): SaaS 형태로 서비스를 제공하거나 제품에 번들링 시, 별도 OEM 계약 없이는 BINARY-LICENSE.md 위반. CloakHQ가 신생 소규모 팀이므로 OEM 계약 조건, 가격, 장기 지속 가능성 불확실.

  2. 버스 팩터(Bus Factor) 극히 낮음: 사실상 1인 프로젝트(기업 스폰서 없음). 핵심 개발자 이탈 시 독점 바이너리 업데이트 중단 → Chromium 업스트림 보안 패치 미반영 위험. 3.5개월 된 신생 프로젝트로 장기 지속 가능성 미검증.

  3. 법적 회색지대 (웹 스크래핑): 봇 탐지 우회를 명시적 목적으로 설계된 도구. 대상 사이트 ToS 위반, CFAA(미국), Computer Misuse Act(영국) 등과의 충돌 가능성. 일부 사용 사례가 법적으로 문제될 수 있으며, 이는 해당 도구를 사용하는 서비스 제공자에게도 위험.

  4. NOTICE/THIRD_PARTY_LICENSES 파일 부재: Apache-2.0, BSD 의존성 귀속 고지가 패키지에 포함되지 않음. ISO 5230 / OpenChain 준수 미달.

  5. P3TERX 비공식 GeoIP 미러: GeoLite2-City.mmdb를 비공식 GitHub 미러에서 다운로드. 공급망 무결성 위험. MaxMind 공식 API(API 키 필요) 또는 공식 검증된 소스 사용 권장.

9. 권고 조치 사항 / Recommended Actions

  1. OEM 라이선스 확인: 배포 목적 및 사용 시나리오 명확화 후 CloakHQ(cloakhq@pm.me)와 접촉하여 OEM 계약 필요 여부 및 조건 확인. SaaS 형태로 제공할 경우 계약 체결 전까지 사용 보류.

  2. 법적 검토 수행: 웹 스크래핑 또는 봇 탐지 우회를 포함하는 상업 서비스에 이 도구를 사용하기 전 법무팀 또는 외부 법률 자문 수행. 주요 검토 영역: 대상 사이트 ToS 위반 위험, CFAA/DMCA 위반 가능성, 지역별 법령 차이.

  3. 바이너리 대안 평가: 상용화 목적으로 독점 바이너리 의존을 장기적으로 유지하기 어렵다면, ungoogled-chromium 기반 자체 빌드 또는 Playwright stealth 대안(Camoufox 등) 병행 평가 시작.

단기 조치 / High (within 30 days)

  2. GeoIP 소스 변경: geoip.py의 P3TERX 비공식 미러 → MaxMind 공식 API(무료 등록 필요) 또는 검증된 대안으로 교체. 공급망 무결성 강화.

  3. SECURITY.md 작성: 취약점 신고 프로세스 정의. 이메일 기반 신고 채널 공식화.

  4. 버스 팩터 대응 계획: 단일 팀 의존성을 인지하고 내부 fork 또는 대체 솔루션 전환 트리거 기준 수립. (예: 3개월 이상 릴리스 중단 시 대안 전환)

중기 조치 / Medium (within 90 days)

  1. 라이선스 스캔 CI 통합: FOSSA, ScanCode Toolkit 또는 pip-licenses/license-checker 등을 CI 파이프라인에 추가. 금지 라이선스 자동 탐지 및 빌드 게이트 설정.

  2. BOM(소프트웨어 명세서) 생성: CycloneDX 또는 SPDX 형식으로 소스 코드 BOM 자동 생성. Docker SBOM에 더하여 소스 패키지 레벨 BOM도 포함.

  3. 운영 모니터링 구현: Prometheus 메트릭 노출, 구조적 JSON 로깅, 헬스체크 엔드포인트 추가 (cloakserve 수준에서 구현 가능). K8s 배포 시 Liveness/Readiness probe 구현.

  4. 멀티테넌시 격리 설계: 여러 고객이 사용하는 환경이라면 Kubernetes namespace 또는 컨테이너 수준 격리, 리소스 제한(CPU/메모리 cgroup) 적용.
