1단계 — 목적 및 범위 정의

한국어

CodeGraph는 AI 코딩 에이전트에게 로컬 기반 시맨틱 코드 인텔리전스를 제공하는 오픈소스 플랫폼이다. 핵심 가치 제안은 세 가지다.

  1. 구조적 이해: tree-sitter AST로 코드베이스를 파싱해 심볼(함수·클래스·변수)과 그 관계(호출·임포트·상속)를 SQLite 지식 그래프에 저장한다.
  2. AI 에이전트 통합: MCP(Model Context Protocol)를 통해 Claude Code, Cursor, Codex CLI, opencode, Gemini CLI, Hermes Agent, Kiro, Antigravity 8개 에이전트와 연동한다.
  3. 성능 향상 검증: 7개 실제 저장소에서 에이전트 A/B 테스트를 수행해 94% 도구 호출 감소, 77% 탐색 시간 단축, 100% 로컬 실행을 공식 문서화했다.

대상 사용자: AI 어시스턴트로 코드를 탐색하는 개발자, MCP 서버를 활용하는 AI 에이전트 플랫폼 운영자, 코드 인텔리전스 라이브러리를 직접 임베딩하는 애플리케이션 개발자.

분류: 라이브러리 + CLI + MCP 서버 (세 가지 소비 방식을 하나의 바이너리로 제공하는 다목적 도구).

English Summary

CodeGraph is a local-first semantic code intelligence platform. It parses any supported codebase using tree-sitter WASM grammars, stores the resulting symbol graph in a per-project SQLite database under .codegraph/, and exposes a structured query layer to AI coding agents over MCP. The project's core differentiation is deterministic, AST-derived extraction (no LLM summarization) and verified benchmarks showing significant reduction in agent tool calls. Version 0.9.9, published as @colbymchenry/codegraph on npm.

4.2 아키텍처 패턴

  • 파이프라인 + 레이어드 아키텍처: 각 단계가 명확히 분리. 추출 → 저장 → 해석 → 질의 → 출력.
  • 퍼사드 패턴: src/index.ts의 CodeGraph 클래스가 모든 레이어를 단일 인터페이스로 노출.
  • 전략 패턴: 언어 추출기, 프레임워크 리졸버, 설치 타겟이 각각 인터페이스를 구현하는 독립 파일로 교체 가능.
  • 동적 디스패치 합성(Dynamic Dispatch Synthesis): callback-synthesizer.ts가 정적 파싱으로는 잡히지 않는 간접 호출(EventEmitter, React setState→render, JSX child, Gin 미들웨어, Swift 클로저 배열)을 provenance:'heuristic' 엣지로 합성. 중요 원칙: "부분적 커버리지는 커버리지 없는 것보다 나쁘다" — 하나의 경계만 브리징하면 다음 경계에서 에이전트가 더 많은 읽기를 수행.
  • 어댑터 패턴: SQLite 백엔드가 node:sqlite(기본)와 better-sqlite3(native) 간 투명하게 전환.

4.3 상태 관리 및 동시성

  • 뮤텍스(in-process) + 파일 잠금(cross-process): 동시 인덱싱 방지.
  • WAL 모드: 쓰기 중에도 읽기 블로킹 없음.
  • 디바운스: FileWatcher가 파일 변경 이벤트를 디바운스 후 자동 동기화.
  • 워커 스레드: parse-worker.ts가 무거운 파싱 작업을 메인 스레드에서 분리.

4.4 MCP 도구 설계 원칙

src/mcp/server-instructions.ts가 에이전트 대면 지침의 단일 진실 원천: - codegraph_explore: 1차 도구 — 심볼 집합으로 호출 경로 탐색 (플로우 질문) - codegraph_node: 2차 도구 — 단일 심볼 전체 본문 + 오버로드 반환 - codegraph_search, codegraph_callers, codegraph_callees, codegraph_impact, codegraph_files, codegraph_status: 보조 도구

설계 철학: "에이전트를 바꾸려 하지 말고 도구가 에이전트에 맞춰라" — 에이전트가 이미 호출하는 도구가 더 많이 반환하도록 설계. 에이전트 행동 변경을 유도하는 접근은 반복 검증에서 실패.

6. 성능 및 확장성 고려사항 / Performance & Scalability

[한국어]

알려진 성능 병목 지점:

  1. 초기 전체 인덱싱 — 대형 저장소(~10,000개 파일)에서 첫 인덱싱 시간. parse-worker.ts가 무거운 파싱을 메인 스레드에서 오프로드하나, 총 시간은 파일 수에 비례

Known performance bottlenecks:

  1. Initial full index — First-time indexing on large repos (~10k files) takes time proportional to file count. parse-worker.ts offloads heavy parsing from the main thread, but total time scales linearly
